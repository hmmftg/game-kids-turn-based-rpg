# {{GAME_NAME_MD}}

This project was generated by `waypoint-rpg game create`. It owns its world,
content, reducer, save policy, renderer, and release decisions. The sample starts
with one accessible 3D scene and imports framework APIs only from their public
package roots.

Framework packages are installed from the local archives in `vendor/`. After
installing the developer toolchain into npm's cache, this project can be
installed without a registry connection:

```sh
npm ci --offline
npm run build
npm test
npm run capture
```

Edit `game.project.json` as the project manifest. Keep authored content in
`src/content/`; asset rights and release approval are recorded in the asset
catalog and must be reviewed separately. The technical preview never grants
release approval.

The generated lockfile pins framework tarballs and development tools. A first
install may need an online cache bootstrap if the required Vite, React, TypeScript,
Vitest, and Playwright packages are not already cached; subsequent installs
can use `npm ci --offline`.

`npm run dev` opens the one-scene game locally. The project does not inherit
private runtime code from another example.
